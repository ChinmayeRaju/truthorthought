🔄 Data Flow Process:

1. User submits news article URL(s) through the frontend interface
2. URL Scraper extracts and processes content from news sources
3. Multi-Role Analyzer applies domain expert analysis for classification
4. Intelligent Chat Assistant provides interactive discussion capabilities
5. Structured analysis results returned to frontend for user interaction
